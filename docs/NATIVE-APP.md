# Peek Pets as a real iPhone app

The iPhone app is the same phone web app (`phone/`) wrapped with **Capacitor 8**
(`app/`), plus a few native wins:

* **"Find your PC"**: the app lists PCs running the companion on your Wi-Fi (Bonjour
  `_peekpets._tcp`), so pairing is *tap your PC → type the code*. No IP address, no QR.
* **No certificate to install**: the app talks plain `ws://` to the PC on your home network
  (iOS "local networking" exception), unlike the web app's installable mode.
* **Haptics** on boops, hugs, eye-pokes and power alerts; **real keep-awake**; **local
  notifications** for timers, finished renders and focus sessions *while the app is open or
  just backgrounded*.
* The website / Home-Screen app keeps working exactly as before.

> **Honest limits.** iOS freezes apps in the background, so the pet can't ping you when the
> app has been closed for a while. Doing that properly needs Apple push notifications through a
> small relay server (see "Future: push" below). I built and checked everything I could from
> Windows, but **nothing here has run on a real iPhone yet**.

> **Have a Mac?** That's the easiest route: [MAC-SETUP.md](MAC-SETUP.md) (clone, one
> script, press ▶ in Xcode; renewing is one click).

## Install option A: Sideloadly (free Apple ID, re-install every 7 days)

1. **Get the app file.** On GitHub open
   [LowLuke99/peek-pets → Actions → "iOS app"](https://github.com/LowLuke99/peek-pets/actions/workflows/ios.yml)
   → **Run workflow** (or push a tag like `v0.2.0`). After ~2 minutes download the
   **PeekPets-unsigned-ipa** artifact and unzip it to get `PeekPets-unsigned.ipa`.
2. **Install Sideloadly** on the PC (sideloadly.io) and **iTunes from Apple's website**
   (not the Microsoft Store version), which Sideloadly needs for the USB driver.
3. Plug the iPhone in with a cable, tap **Trust** on the phone.
4. In Sideloadly drag in the `.ipa`, type your **Apple ID**, click **Start**. It signs the app
   with a free 7-day certificate. (Use a secondary Apple ID if you prefer.)
5. On the iPhone: **Settings → General → VPN & Device Management → your Apple ID → Trust**.
   On iOS 16+ also turn on **Settings → Privacy & Security → Developer Mode** (it restarts).
6. Open **Peek Pets**. When iOS asks *"find devices on your local network"*, tap **Allow**
   (without it the app can't see your PC). Pick your PC, type the code from the companion window.

Free certificates expire after **7 days**: plug in and press Start in Sideloadly again (your
pet and its bond level are kept). Free Apple IDs can have 3 sideloaded apps at once.

## Install option B: TestFlight (paid Apple Developer account, $99/year)

No cable, no 7-day expiry (TestFlight builds last 90 days), and friends can test too.
Everything is prepared; it only needs your account details as GitHub secrets:

1. Enrol at developer.apple.com, then in **App Store Connect → Apps → +** create an app with
   bundle ID **`com.lowluke.peekpets`** (register it under Identifiers first).
2. **App Store Connect → Users and Access → Integrations → App Store Connect API → +**: create
   a key with *App Manager* access. Note the **Key ID** and **Issuer ID**; download the `.p8`.
3. In GitHub: **Settings → Secrets and variables → Actions → New repository secret**:

   | Secret | Value |
   |---|---|
   | `ASC_KEY_ID` | the Key ID |
   | `ASC_ISSUER_ID` | the Issuer ID |
   | `ASC_KEY_P8_BASE64` | the `.p8` file, base64 encoded (PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("AuthKey_XXXX.p8"))`) |
   | `APPLE_TEAM_ID` | your 10-character Team ID (Membership page) |

4. Actions → **"iOS TestFlight"** → Run workflow. The fastlane lane
   (`app/ios/App/fastlane/Fastfile`) creates the signing certificate and profile with the API
   key, builds, and uploads. After Apple processes it (~10–30 min) install **TestFlight** on
   the iPhone and accept the build.

## Building it yourself

```
cd app
npm install
npm run sync          # copies ../phone into www/ and syncs native plugins
npm run open          # opens Xcode (macOS only)
```

`app/ios` is committed (generated by `npx cap add ios`, which even works on Windows). Our own
native code: `app/ios/App/App/PeekDiscoveryPlugin.swift` (Bonjour browse with `NWBrowser`;
the companion's TXT record carries its IP and port) and `PeekBridgeViewController.swift` (registers
it). Info.plist adds `NSAllowsLocalNetworking`, `NSLocalNetworkUsageDescription` and
`NSBonjourServices = _peekpets._tcp`.

CI cost: the unsigned build took **1m25s** on a macOS runner (macOS minutes count 10× on
private repos, so ≈15 of the 2,000 free minutes). It only runs when you ask.

## Future: push notifications (decision for you)

To nudge you when the app is closed, the PC would send events to a tiny relay (e.g. a free
Cloudflare Worker) that forwards them to Apple Push Notification service. That needs the paid
developer account (APNs key), a little hosting, and sends event names (not screen contents)
off your network. Not built; say the word if you want it.
